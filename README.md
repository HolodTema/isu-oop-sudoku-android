## SUDOKU Kotlin Android JNI Application

Game process is working in C++ code, which is connected to the application using Java Native
Interface (JNI). Three screens, three levels of difficulty of sudoku.

### Used technologies: 

Kotlin, Android SDK, Jetpack Compose

Multi-module Clean Architecture, MVI

Java Native Interface (JNI)

C++ and STL

Navigation Component

Dagger/Hilt

Timber

AndroidX Startup Library

JUnit, MockK

Github Actions CI/CD
